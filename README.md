# Mykal's Agent Config

This repo contains a bunch of useful markdown and config files for doing my type of work with agents.

I use these files in Claude Code, GitHub Copilot, and in OpenCode. You can use them anywhere an agent can read markdown.

## Skills

This folder contains skills for agents. Each skill is focussed on a specific tool chain or area of expertise (domain, one could say?) that you want your agent to have skills in.

## Agents

This folder contains "role" documents for specific roles that you want your agents to take on. I used to have like 50 of these and used none of them. I cut them down to 5-6 that actually map to what my typical work looks like.
